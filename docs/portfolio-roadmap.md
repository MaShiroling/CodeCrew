# CodeCrew 精简开发路线（简历展示版）

更新日期：2026-10-01。本页是**当前路线与进度真相源**。此前的
[15 步计划](development-plan.md)保留为历史实现记录；其中尚未启动的评测平台
和通用平台化步骤不再自动排进当前开发顺序。

## 产品定位

CodeCrew 是面向开发协作的独立多 Agent 聊天室：Human 与白金（方案）、
月见（实现）、鲸鲸（评审）在同一房间讨论，成员可通过结构化消息邀请队友接话。
默认只读、无需指定 Git 仓库；只有 Human 明确授权一个具体仓库的编码任务时，
才进入现有受控代码工作流。借鉴 Clowder AI 的团队协作思路，但不复制其代码、
Prompt、界面或品牌资源。

本版的目标是一个可现场演示、可解释技术取舍、可重复运行的个人项目，
不是通用 Agent 平台，也不是正式可靠性评测平台。

## 本版明确不做

- 不复制猫咖的共享长期记忆、插件/MCP Hub、IM 网关、语音、游戏、多用户和桌面安装包。
- 不继续扩展原 15 步中的正式评测集、多语言任务、对照实验、Token 成本统计
  或对 Agent 真正保密的隐藏测试环境。现有相关代码保留，不因路线调整仓促删除。
- 不把 Planner/Implementer/Reviewer 的自然语言结论当作代码任务成功证据；
  不取消聊天只读、显式写入授权、密钥环境变量和已有测试这些安全底线。

## 演示主线

1. 打开独立聊天室，新建一个房间；不填写 Git 路径。
2. `@白金` 讨论方案，白金邀请月见补充实现风险，再由鲸鲸指出验证边界。
3. 刷新页面，仍能看到消息与回合状态；展示失败或取消的可见反馈。
4. 如需实际改代码，由 Human 对一个示例仓库显式授权一次小修复，查看 Diff
   和测试证据。此步是聊天后的独立操作，不由 Agent 在讨论中自行升级权限。
